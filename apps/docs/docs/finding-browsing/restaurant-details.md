## Top Section
- Average rating (calculated from user reviews)
- Open/Closed status
- Price per person
- Cuisine

## Media Gallery
- Photos and YouTube videos

## Info Cards
- Price  
- Cuisine  
- Phone number  
- Website (if available)  
- Menu (if available)  

If some information is missing, the card appears **faded (50% opacity)**.

## Location & Hours
- Embedded Google Map  
- Restaurant address  
- Weekly working hours

If you notice incorrect working hours, click **“Wrong info?”** to request changes.

## Amenities
Each amenity shows as either:
- **Available**, or
- **Not available** (faded out)
