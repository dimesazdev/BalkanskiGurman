## Home Page
The home page has a **“See All Restaurants”** button. Clicking it starts the restaurant discovery flow.

## Restaurant Map & Selection
1. First, you’ll see the **Ex‑Yu Map**.
2. Choose a **country** and then a **city** from the Ex‑Yu region (**Kosovo excluded**).
3. After selecting, the site displays all restaurants in that location.
