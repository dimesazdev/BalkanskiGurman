## Domača stran
Na domači strani je gumb **»Poglej restavracije«**. S klikom se začne pot odkrivanja.

## Zemljevid in izbira
1. Najprej se prikaže **zemljevid Ex‑Yu**.
2. Izberite **državo** in nato **mesto** iz regije (**Kosovo je izključeno**).
3. Po izbiri se prikažejo vse restavracije na tej lokaciji.
