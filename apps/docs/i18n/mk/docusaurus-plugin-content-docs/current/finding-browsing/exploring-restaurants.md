## Почетна страница
На почетната страница има копче **„Погледни ги рестораните“**. Со клик започнува процесот на пронаоѓање.

## Мапа и избор
1. Прво се прикажува **Ex‑Yu мапата**.
2. Изберете **држава**, па **град** од регионот (**Косово е исклучено**).
3. По изборот, ќе се прикажат сите ресторани на таа локација.
